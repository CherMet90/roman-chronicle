# The Roman Chronicle — Hugo‑блог

Исторический блог о Древнем Риме, созданный на Hugo с использованием темы Charaka и автоматическим деплоем через GitHub Pages.

## Структура проекта

```
├── .github/workflows/hugo.yml    # GitHub Actions workflow для сборки и деплоя
├── archetypes/                   # Шаблоны генерации контента
│   ├── posts.md                  # Шаблон обычного выпуска (новости, топ, экономика, ЧП)
│   └── special.md                # Шаблон спецвыпуска (расследование, аналитика)
├── content/posts/                # Посты (каждый пост — папка‑bundle)
│   └── 001-tarquins-forum/
│       ├── index.md              # Текст поста
│       └── *.jpg/png             # Изображения, относящиеся к посту
├── layouts/                      # Переопределённые шаблоны темы
│   ├── _default/
│   │   ├── single.html           # Шаблон отдельного поста
│   │   └── list.html             # Шаблон списка постов
│   ├── index.html                # Шаблон главной страницы
│   └── partials/                 # Частичные шаблоны (хедер, футер и т.д.)
├── scenarios/
│   └── arc-XX-Название.md        # Сценарии/шаблоны для арки/нескольких выпусков
├── static/                       # Статические файлы (иконки, CSS, JS)
│   ├── css/styles.css            # Дополнительные стили
│   └── favicon.*                 # Иконки сайта
└── hugo.toml                     # Конфигурация Hugo
```

## Сценарии и историческая рецензия

- В проекте есть папка `scenarios/`, где хранятся сценарии выпусков (по одной или нескольким аркам).
- **Для каждого сценария создаётся отдельный Markdown-файл** со структурой будущих публикаций.
- **Каждый сценарий дополняется рецензией историка,** где разбирается степень его исторической достоверности, а также предлагаются рекомендации по усилению историчности.
- Рецензия оформляется в виде отдельного текстового блока после получения соответствующего запроса

## Создание нового выпуска

Все выпуски — и обычные, и спецвыпуски — размещаются в `content/posts/` и имеют **сквозную нумерацию** (например: выпуск 5 → спецвыпуск 6 → выпуск 7).

### Обычный выпуск (новостной формат)

Используется шаблон `posts.md` (структура: Топ недели, Экономика, Культура, ЧП).

```bash
hugo new posts/007-regular-issue/index.md
```
(Hugo автоматически выберет `archetypes/posts.md`, так как имя совпадает с секцией `posts`)

### Спецвыпуск (аналитический формат)

Используется шаблон `special.md` (структура: расследование, свидетельства, аналитические блоки).

```bash
hugo new --kind special posts/006-special-fall/index.md
```

**Важно:** Ключ `--kind special` принудительно указывает использовать файл `archetypes/special.md` вместо стандартного.

### Заполнение контента

1. **Открой сгенерированный** `index.md`. Вверху будет фронт-маттер с комментариями-инструкциями (в HTML-блоках `<!-- ... -->`), которые укажут, как заполнять каждый раздел.
2. **Помести изображения** в ту же папку, что и `index.md`. Ссылки на них внутри поста относительные: `image-name.jpg`.
3. **Убедись, что поле** `issue:` **соответствует нумерации папки** (даже для спецвыпуска).
4. **Для публикации** измени `draft: true` на `draft: false` (или удали строку).

## Работа с черновиками

- Пока `draft: true`, пост **не публикуется** на GitHub Pages (хотя локально виден при `hugo server -D`).
- Чтобы опубликовать, измени на `draft: false` или удали строку.

## Стилизация

- Заголовки `h2` и `h3` внутри поста автоматически центрируются и имеют отступ сверху.
- Дополнительные стили можно добавлять в `static/css/styles.css`, оборачивая их в класс `.post-body` (чтобы не затронуть остальной сайт).

## Локальная разработка

1. Убедись, что тема установлена:

```bash
git clone https://github.com/natarajmb/charaka-hugo-theme.git themes/charaka-hugo-theme
```

2. Запусти локальный сервер:

```bash
hugo server -D      # с черновиками
# или
hugo server         # только опубликованные
```

   Сайт будет доступен по адресу `http://localhost:1313/roman-chronicle/`.

## Деплой

При пуше в ветку `main` автоматически запускается GitHub Actions workflow (файл `.github/workflows/hugo.yml`), который:

1. Устанавливает Hugo.
2. Клонирует тему.
3. Собирает сайт (только посты с `draft: false`).
4. Деплоит результат на GitHub Pages.

Сайт доступен по адресу: `https://chermet90.github.io/roman-chronicle/`

## Настройки

Основные настройки сайта хранятся в `hugo.toml`:

- `baseURL` — базовый адрес сайта (важно для корректных ссылок).
- `title` — название сайта.
- `theme` — используемая тема.
- `relativeURLs` — относительные ссылки (включено для работы на GitHub Pages).

**Важно:** чтобы HTML работал, в `hugo.toml` должна быть строка:
```toml
[markup.goldmark.renderer]
unsafe = true
```
