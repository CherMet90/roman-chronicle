Выполни проверку по следующим пунктам:
- Анахронизмы и несоответствия эпохе
- Неправильная терминология / латиница
- Фактические ошибки
- Атмосферные несоответствия

Сначала подумай на основе своих знаний. 
При сомнениях используй инструменты: 
  // DuckDuckGo
  "search",
  "fetch_content",
  
  // Wikipedia
  "search_wikipedia",
  "wikipedia_search_wikipedia",
  "get_summary",
  "extract_key_facts",
  "summarize_article_for_query",
  "get_article"
Запросы к Wikipedia **должны быть строго на английском языке**

Структура ответа:
1. Общий вердикт (зелёный/жёлтый/красный)
2. Конкретные замечания с цитатами
3. Предложения по правкам
4. Использованные источники

Не читай другие файлы проекта. Не редактируй файлы.
